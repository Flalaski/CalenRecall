# Calendar System Research Sources

This document provides comprehensive academic and authoritative sources for all calendar implementations in CalenRecall.

## Primary References

### Core Algorithm Sources

1. **Dershowitz, Nachum, and Edward M. Reingold**
   - *Calendrical Calculations: The Millennium Edition*
   - Cambridge University Press, 2001 (3rd edition)
   - ISBN: 978-0521777520
   - **Usage**: Primary source for conversion algorithms for all calendar systems
   - **Status**: Authoritative reference for calendrical calculations
   - **URL**: Available through Cambridge University Press

2. **Meeus, Jean**
   - *Astronomical Algorithms*
   - Willmann-Bell, 1998 (2nd edition)
   - ISBN: 978-0943396635
   - **Usage**: Astronomical calculations and calendar algorithms
   - **Status**: Standard reference for astronomical calculations
   - **URL**: Available through Willmann-Bell

3. **Bickerman, E.J.**
   - *Chronology of the Ancient World*
   - Cornell University Press, Ithaca, NY, 1968 (revised edition 1980)
   - ISBN: 978-0801412821
   - **Usage**: Historical chronology and calendar evolution
   - **Status**: Authoritative reference for ancient calendars
   - **URL**: Available through Cornell University Press

4. **Doggett, L.E.**
   - "Calendars"
   - In: *Explanatory Supplement to the Astronomical Almanac*
   - University Science Books, Sausalito, CA, 1992
   - **Usage**: Comprehensive calendar system reference
   - **Status**: Standard reference in astronomical almanacs
   - **URL**: Available through University Science Books

## Calendar-Specific Sources

### Gregorian Calendar

1. **Richards, E.G.**
   - *Mapping Time: The Calendar and Its History*
   - Oxford University Press, 1998
   - ISBN: 978-0198504139
   - **Usage**: Historical development of Gregorian calendar
   - **Key Information**: Regional adoption dates, reform details

2. **Duncan, David Ewing**
   - *The Calendar: The 5000-Year Struggle to Align the Clock and the Heavens*
   - Fourth Estate, 1998
   - ISBN: 978-1857029796
   - **Usage**: Historical context and evolution

3. **Official Sources**:
   - Papal Bull *Inter gravissimas* by Pope Gregory XIII (1582)

### Julian Calendar

1. **Richards, E.G.** (see above)
   - **Key Information**: Historical development, Augustus reforms (8 CE)

2. **Bickerman, E.J.** (see above)

3. **"Evolution of Calendars"**

## Verification Standards

### Algorithm Verification

All calendar algorithms are verified against:
1. Primary sources (Dershowitz & Reingold, Meeus)
2. Reference implementations (Fourmilab, academic implementations)
3. Known historical dates and events
4. Cross-referencing with multiple sources

### Historical Accuracy

Historical information is verified against:
1. Academic historical sources
2. Primary historical documents where available
3. Multiple scholarly references
4. Cultural and community sources (for cultural calendars)

## Citation Format

When referencing sources in documentation:
- **Books**: Author, Title, Publisher, Year, ISBN (if available)
- **Academic Papers**: Author, Title, Journal/Conference, Year
- **Websites**: Title, URL, Date accessed
- **Official Sources**: Organization, Document Title, Date
